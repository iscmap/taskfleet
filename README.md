\# TaskFleet



TaskFleet is a microservices-based logistics and order processing platform

built with Java 21, Spring Boot, AWS, and Gradle.



\## Tech Stack

\- Java 21

\- Spring Boot

\- Gradle (Groovy)

\- AWS (ECS, RDS, DynamoDB, SQS, S3)

\- Docker

\- GitHub Actions



\## Architecture

\- Microservices

\- Async event-driven processing

\- Cloud-native design



This project is intended as a production-grade learning and interview showcase.
